# InternTrack

A student-focused platform to discover internships/jobs, track applications, and prep for interviews.

## Tech
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Develop locally
1. Install dependencies
```
npm install
```
2. Start the dev server
```
npm run dev
```
Visit http://localhost:3000

## Project structure (high level)
- `app/` routes and pages
- `components/` UI components
- `styles/` global styles

## Notes
- Environment variables are required for some features (auth, data, etc.) and must be provided via a local `.env.local` file or your hosting provider's environment settings. This file is intentionally not included in the repository.
- Operational details (deployment, auth providers, domains, and credentials) are documented in private project docs.
